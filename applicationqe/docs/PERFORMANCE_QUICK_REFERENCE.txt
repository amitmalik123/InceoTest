📊 WHAT IT MONITORS
───────────────────────────────────────────────────────────────────────────
✓ Web Vitals (LCP, FID, CLS, TTFB, FCP)
✓ Navigation Timing (DNS, TCP, request/response, DOM processing)
✓ Resource Metrics (scripts, styles, images, fonts - count & size)
✓ Memory Usage
✓ Performance Budgets
✓ Lighthouse Audits (Performance, A11y, SEO, Best Practices, PWA)

🚀 QUICK START
───────────────────────────────────────────────────────────────────────────

1. AUTO MONITORING (Simplest):

   @pytest.mark.performance
   def test_my_page(page: Page, performance_monitor):
       page.goto("https://example.com")
       # Metrics collected automatically!

2. MANUAL MONITORING (More Control):

   from utils.performance_monitor import PerformanceMonitor

   def test_manual(page: Page):
       monitor = PerformanceMonitor(page)
       monitor.start_monitoring()
       page.goto("https://example.com")

       metrics = monitor.collect_metrics("test_name")
       monitor.save_metrics(metrics)
       print(monitor.generate_report(metrics))

3. CUSTOM BUDGET:

   from utils.performance_monitor import PerformanceBudget

   budget = PerformanceBudget(
       lcp_max=2000,
       fcp_max=1500,
       total_size_max_kb=1500
   )
   monitor = PerformanceMonitor(page, budget=budget)

4. LIGHTHOUSE AUDIT:

   from utils.lighthouse_runner import LighthouseRunner

   @pytest.mark.lighthouse
   def test_lighthouse(page: Page):
       runner = LighthouseRunner()
       result = runner.run_audit("https://example.com")
       scores = runner.extract_scores(result)
       assert scores.performance >= 90

📝 PERFORMANCE MARKERS
───────────────────────────────────────────────────────────────────────────
@pytest.mark.performance  → Enable auto performance monitoring
@pytest.mark.lighthouse   → Run Lighthouse audit (slow, requires npm)

▶️ RUN COMMANDS
───────────────────────────────────────────────────────────────────────────
# Run all performance tests
pytest -m performance -v

# Run Lighthouse tests
pytest -m lighthouse -v

# Run specific performance test
pytest tests/performance/test_performance_example.py -v

# Run with performance report output
pytest -m performance -v -s

🎯 PERFORMANCE BUDGETS (Default)
───────────────────────────────────────────────────────────────────────────
LCP (Largest Contentful Paint):    ≤ 2500ms
FID (First Input Delay):            ≤ 100ms
CLS (Cumulative Layout Shift):      ≤ 0.1
TTFB (Time to First Byte):          ≤ 800ms
FCP (First Contentful Paint):       ≤ 1800ms
Page Load:                          ≤ 3000ms
Total Size:                         ≤ 2000KB

See config/performance_budgets.yaml for environment-specific budgets

💡 USAGE EXAMPLES
───────────────────────────────────────────────────────────────────────────

TEST SINGLE PAGE:
   @pytest.mark.performance
   def test_homepage(page, performance_monitor):
       page.goto("https://example.com")

TEST MULTIPLE PAGES:
   @pytest.mark.performance
   def test_pages(page):
       for url in ["page1", "page2", "page3"]:
           monitor = PerformanceMonitor(page)
           monitor.start_monitoring()
           page.goto(url)
           metrics = monitor.collect_metrics(url)
           monitor.save_metrics(metrics)

TEST USER JOURNEY:
   def test_journey(page):
       monitor = PerformanceMonitor(page)

       # Step 1
       monitor.start_monitoring()
       page.goto("home")
       home_metrics = monitor.collect_metrics("home")

       # Step 2
       monitor.start_monitoring()
       page.click("link")
       next_metrics = monitor.collect_metrics("next")

LIGHTHOUSE AUDIT:
   @pytest.mark.lighthouse
   def test_audit(page):
       runner = LighthouseRunner()

       # Desktop
       result = runner.run_audit("https://example.com",
                                 form_factor="desktop")
       scores = runner.extract_scores(result)
       assert scores.performance >= 90

       # Mobile
       mobile = runner.run_audit("https://example.com",
                                 form_factor="mobile")
