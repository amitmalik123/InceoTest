================================================================================
                    SONARQUBE QUICK REFERENCE
================================================================================

📋 QUICK START COMMANDS

Windows PowerShell:
-------------------
# Run SonarQube analysis with parameters
.\run_sonar_analysis.ps1 -SonarHost "http://sonarqube.com" -SonarToken "your-token"

# Local development (localhost:9000)
.\run_sonar_analysis.ps1 -Local -SonarToken "your-token"

# Skip tests (use existing reports)
.\run_sonar_analysis.ps1 -SkipTests

# Custom project key
.\run_sonar_analysis.ps1 -ProjectKey "custom-key"


Makefile (Linux/Mac/WSL):
--------------------------
make sonar              # Full SonarQube analysis
make sonar-local        # Local SonarQube server (localhost:9000)
make test-coverage      # Run tests with coverage only
make quality-reports    # Generate quality reports only


Manual Commands:
----------------
# 1. Generate quality reports
mkdir -p reports
flake8 --output-file=reports/flake8-report.txt pages utils config fixtures
mypy pages utils config fixtures > reports/mypy-report.txt
bandit -r pages utils config fixtures -f json -o reports/bandit-report.json

# 2. Run tests with coverage
pytest tests/ \
  --cov=pages --cov=utils --cov=config --cov=fixtures \
  --cov-report=xml:reports/coverage.xml \
  --junitxml=reports/junit.xml

# 3. Run SonarScanner
sonar-scanner \
  -Dsonar.projectKey=python-playwright-automation \
  -Dsonar.host.url=$SONAR_HOST_URL \
  -Dsonar.login=$SONAR_TOKEN

================================================================================
🐳 LOCAL SONARQUBE SERVER
================================================================================

Docker Setup:
-------------
# Start SonarQube container
docker run -d --name sonarqube -p 9000:9000 sonarqube:latest

# Access SonarQube
http://localhost:9000
Default credentials: admin/admin

# Stop SonarQube
docker stop sonarqube

# Remove SonarQube
docker rm sonarqube

================================================================================
🛠️ TROUBLESHOOTING
================================================================================

Common Issues:
--------------

1. SonarScanner Not Found
   Windows:     Add C:\sonar-scanner\bin to PATH
   Linux/Mac:   Add /opt/sonar-scanner/bin to PATH

2. Authentication Failed
   - Verify SONAR_TOKEN is correct
   - Check token hasn't expired
   - Regenerate token if needed

3. Coverage Report Not Found
   - Ensure pytest-cov is installed: pip install pytest-cov
   - Run tests first to generate reports

4. Quality Gate Failed
   - Check SonarQube dashboard for issues
   - Review coverage metrics
   - Fix reported bugs/vulnerabilities

5. Port 9000 in Use
   Windows:     netstat -ano | findstr :9000
   Linux/Mac:   lsof -ti:9000


Debug Mode:
-----------
sonar-scanner -X -Dsonar.verbose=true


Check Logs:
-----------
SonarQube Server:    $SONARQUBE_HOME/logs/sonar.log
Scanner Work:        .scannerwork/report-task.txt


================================================================================
📚 QUALITY METRICS EXPLAINED
================================================================================

Bugs:
-----
Code that is demonstrably wrong or highly likely to cause unexpected behavior.
Target: 0 bugs

Vulnerabilities:
----------------
Security-related issues that can be exploited by attackers.
Target: 0 vulnerabilities

Code Smells:
------------
Maintainability issues in code that could make it harder to maintain.
Target: Minimize code smells

Technical Debt:
---------------
Estimated time to fix all code smells and maintainability issues.
Target: Minimize technical debt

Coverage:
---------
Percentage of code executed by tests.
Target: >= 80%

Duplications:
-------------
Percentage of duplicated code blocks.
Target: < 3%

5. Quality Gates
   Ensure all quality gates pass before merging

6. Security Hotspots
   Review and fix security hotspots

7. Technical Debt
   Monitor and reduce technical debt over time

8. Clean Code
   Follow SonarQube recommendations
