STP Pages Migration Proposal

PROBLEM STATEMENT
-----------------
All 58 STP page objects live in a flat unstructured folder on the ES2PlaywrightPython
branch (pages/*.py) with no team/domain separation. The STP branch pipeline (stp.yml)
points to applicationqe/pages/stp/ which is currently empty — blocking all test execution.

PROPOSED SOLUTION
-----------------
Extract STP-relevant pages from ES2PlaywrightPython and place them into structured
sub-domain folders under applicationqe/pages/stp/ on the STP branch.
